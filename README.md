One-line office joke entry for make.fun's "Make the AI Judge Laugh: the Office Joke Open" bounty. A deterministic, standard-library-only Python program writes a single joke about office life (at most 200 characters) to `/output/entry.txt`. The judge is a stand-up-comic model that compares jokes head to head; the funniest line takes the $2 winner-takes-all prize.

## Run it

```sh
python3 main.py
```
